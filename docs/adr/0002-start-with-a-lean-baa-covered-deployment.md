# Start with a lean BAA-covered deployment

The real-data pilot will run on a small Linux deployment using only services covered by an appropriate business associate agreement, targeting no more than $75 per month before a second customer. PostgreSQL may initially share the application VM with encrypted off-machine backups to keep the pilot economical; managed PostgreSQL becomes appropriate when revenue justifies reducing that operational burden. Development and demonstrations will use synthetic data until the contractual and compliance chain is understood.
